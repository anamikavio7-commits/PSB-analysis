# PSB Tomato Analysis

Python-based statistical analysis of phosphate-solubilizing bacteria (PSB) effects on plant growth in tomato.

## Project Overview

This project contains the Python/Google Colab analysis of an experimental study evaluating phosphate-solubilizing bacterial isolates for plant growth promotion in two tomato varieties:

- Srijana
- BL-410

The study included an initial germination-stage screening followed by a seedling assay of selected treatments.

## Data Analyzed

The analysis includes measurements of:

- Root length
- Shoot length
- Total plant length
- Fresh weight
- Germination
- Seedling Vigor Index (SVI)

## Statistical Analysis

The analysis was performed using Python and includes:

- Data inspection and descriptive statistics
- Mean, standard deviation, and sample size
- One-way ANOVA
- Fisher's Least Significant Difference (LSD) following significant ANOVA results
- Germination percentage
- Seedling Vigor Index (SVI)
- Chi-square analysis of germination counts

The analysis uses `pandas`, `NumPy`, and `SciPy` and was developed in Google Colab.

This project demonstrates the application of Python-based statistical analysis to experimental plant science data, focusing on PSB-mediated plant growth promotion in tomato.
